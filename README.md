# Gloddia Website

Modern PHP web sitesi.

## Özellikler

- Temiz PHP mimarisi
- Modern, responsive tasarım
- Gradient efektleri ve animasyonlar
- İletişim formu

## Kurulum

1. Dosyaları web sunucu dizinine yerleştirin (örn: `htdocs/gloddia-website`)
2. `http://localhost/gloddia-website/` adresinden erişin

## Sayfalar

- `index.php` - Ana sayfa
- `about.php` - Hakkımızda
- `contact.php` - İletişim
- `team.php` - Ekibimiz

## Gereksinimler

- PHP 7.4+
- Web sunucu (Apache/Nginx)
